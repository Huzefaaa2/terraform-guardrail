# TerraGuard Brand Assets

This folder contains the TerraGuard brand system assets for GitHub README, Wiki, LinkedIn posts,
presentation covers, article headers, app tiles, and documentation.

## Usage

| Asset | Recommended use |
| --- | --- |
| `terraguard_logo_cinematic_brand_card_4k.png` | GitHub README hero, LinkedIn banners, launch posts, video title cards. |
| `terraguard_logo_brand_sheet_4k.png` | Brand system documentation and identity overview. |
| `terraguard_logo_horizontal_transparent_dark_text_4000x1200.png` | Light backgrounds, documentation headers, slides. |
| `terraguard_logo_horizontal_transparent_light_text_4000x1200.png` | Dark backgrounds, README/wiki hero areas, videos. |
| `terraguard_logo_icon_dark_square_2048.png` | App tile, avatar, social profile, dark square icon. |
| `terraguard_logo_icon_transparent_2048.png` | Transparent icon, favicon source, watermark, overlays. |
| `terraguard_logo_horizontal_editable.svg` | Editable horizontal vector logo. |
| `terraguard_logo_mark_editable.svg` | Editable icon/mark vector logo. |

## Meaning

- Shield: enterprise governance boundary.
- T monogram: Terraform and infrastructure-as-code building blocks.
- G arc: guardrail loop for policy decisions.
- Nodes: multi-cloud policy surfaces and control evidence points.
- Bottom rails: pass, warn, and block governance decisions.
