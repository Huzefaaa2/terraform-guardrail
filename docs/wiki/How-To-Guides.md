## Suggested first workflow

1. Scan a small Terraform folder locally.
2. Click a default rule to understand what was detected.
3. Create an enterprise policy that adds owner, standard, control, and remediation metadata.
4. Add the policy to an org baseline or group binding.
5. Run a drift gate before apply.
6. Export CI evidence when the workflow is ready for teams.
